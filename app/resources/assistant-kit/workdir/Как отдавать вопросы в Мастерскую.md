# Как отдавать вопросы в Ye!Studio

Автор вставляет одобренные вопросы в пак кнопкой **«Вставить из AI»**: копирует твой блок json
кнопкой «Копировать» в чате, Ye!Studio сама раскладывает вопросы по темам и подбирает картинки
в Яндекс.Картинках. Поэтому, когда автор одобрил вопросы (или просит «дай для Ye!Studio»):

- выдай **один** блок ```json — только одобренные вопросы, без комментариев внутри;
- текст до и после блока можно, Ye!Studio его пропустит.

## Формат

```json
{
  "v": 1,
  "themes": [{
    "round": 3,
    "name": "Место под маской",
    "comment": "Кого сыграло это место?",
    "questions": [{
      "price": 300,
      "type": "simple",
      "text": "Кого сыграл этот город?",
      "image": "Дубровник городские стены",
      "answer": "Королевская Гавань («Игра престолов»)",
      "answerImage": "Королевская Гавань кадр Игра престолов",
      "accept": ["Игра престолов"],
      "options": null
    }]
  }]
}
```

| Поле | Что это |
|---|---|
| `round` | номер раунда с 1, как на табло (финал — последний номер) |
| `name` | тема. Если в паке уже есть тема с таким названием в этом раунде — вопрос встанет в неё, иначе создастся новая |
| `comment` | комментарий к теме (только для новой) |
| `price` | цена. Занята готовым вопросом — Ye!Studio поставит на ближайшую свободную и покажет это |
| `type` | `simple`, `secret` (кот в мешке), `secretPublicPrice`, `stake` (аукцион), `stakeAll`, `forAll`, `noRisk` |
| `text` | текст вопроса; для «угадай по картинке» можно пусто |
| `image` | **запрос для Яндекс.Картинок**, не ссылка. Нет поля — вопрос без картинки |
| `answer` | правильный ответ; при `options` — текст правильного варианта |
| `answerImage` | запрос для картинки в ответе |
| `accept` | ещё засчитываемые ответы: **не меньше 3** (рус/англ, сленг, сокращения, «достаточно франшизы») |
| `options` | варианты ответа (массив строк) или `null` |
| `bonus` | частичный зачёт или бонус — допишется к тексту вопроса в скобках: `"x2, если назовёте и город"`, `"0.5 за тайтл"` |
| `answerText` | что показать на экране при ответе — подпись-панчлайн к картинке ответа («Финансист — Джеффри Эпштейн») |
| `wrong` | 0–2 реплики ведущему на ожидаемые ошибки: `["Нет, Скайрим не инди-игра"]` → `<wrong>` пака |
| `host` | реплика ведущего: читается вслух, на экран не выводится (вместо длинного текста на экране) |
| `video` / `answerVideo` | какое видео найти в вопрос / в ответ. Поиска видео в окне пока нет: встанет пометкой `[🎬 найти: …]` |

## Как писать `image`

- Так, как автор вбил бы в Яндекс: конкретно — кто/что, «кадр из …», год, место.
  Хорошо: `замок Алнвик`, `Королевская Гавань кадр Игра престолов`. Плохо: `замок`, `красивое место`.
- Если картинка стоит **в вопросе**, запрос не должен выдавать ответ на картинке (подписи, логотипы):
  ищем объект, а не «ответ».
- Автор выбирает из первых шести находок; не нашлось — в текст вопроса встанет пометка
  `[🖼 найти: запрос]`, и вопрос будет виден на табло как недоделанный.

Звук и видео пока не вставляются — для видео пиши `video` / `answerVideo`, для звука — в `text`, что искать.
