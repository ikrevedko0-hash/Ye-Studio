# Паки SIGame через разметку

Автор пишет паки «Своей игры» (SIGame). Ты предлагаешь темы и вопросы, автор размечает их на
странице-разметчике (✓/✕, правка на месте), одобренное уходит в «Ye!Studio» — приложение
для сборки паков. Код Ye!Studio не трогай — только предлагай идеи и готовь файлы.

## Где всё лежит

- Рабочая папка: `{{WORKDIR}}`. **Все результаты сохраняй туда**, а не только в чат. Нет доступа к
  папке — попроси автора подключить её (в Claude Desktop — выбрать папку для работы) и до тех пор
  отдавай файлы на скачивание.
- `Гайд по вкусу.md` — прочитай перед любой пачкой тем или вопросов. Начальная версия — общие принципы;
  после каждой разметки дописывай туда, что этому автору нравится и что нет (коротко, с примерами).
- `Как отдавать вопросы в Мастерскую.md` — формат JSON для кнопки «Вставить из AI».
- `инструменты\`:
  - `шаблон разметки тем.html`, `шаблон разметки вопросов.html` — шаблоны, в которых строка `/*DATA*/null`
    заменяется на JSON пачки;
  - `собрать разметку.py <пачка.json> <выход.html>` — делает эту замену (шаблон выбирается по `stage`).
    Нет Python — сделай замену сам: прочитай шаблон, подставь JSON (экранировав `</` как `<\/`), сохрани `.html`;
  - `вставить тему в пак.py <пак.siq> <тема.json>` — тема с картинками с диска прямо в .siq;
  - `пример пачки тем.json`, `пример пачки вопросов.json` — образцы формата. Держись их полей.
- `входящие\` — копии JSON каждой пачки; `отзывы-<batch>.json` — разметка автора (сохраняет сам со страницы).

## Порядок работы

1. **Темы.** 15–20 тем по гайду: одна механика «узнай X по Y», основа — картинка, 7 ступеней сложности,
   риски, сверка с уже бывшими темами. Пачка `stage: "themes"` → страница `Разметка тем — <пак>.html`
   в рабочую папку, копия JSON во `входящие\`. Скажи автору открыть страницу в браузере.
2. Автор жмёт «Сохранить отзывы» и кладёт `отзывы-<batch>.json` в рабочую папку (или прикладывает в чат).
   Прочитай. «Доработать» = тема подходит, дело в вопросах.
3. **Вопросы.** По 8–10 вариантов на тему, `stage: "questions"`. Поля: price, text (коротко: часто пусто
   или 2–3 слова), image (запрос для Яндекс.Картинок, не выдающий ответ), answer, answerImage, accept,
   options. Уже взятые вопросы из прошлых отзывов помечай `pre: true`. Цены — по узнаваемости: раунд 1 —
   100–700, раунд 2 — 200–1400, раунд 3 — 300–2100, в теме 7 вопросов. Факты, в которых не уверен,
   проверяй поиском и честно помечай непроверенное в `note` темы.
4. Страница вопросов: одна тема — одна страница, ✓/✕, правка на месте, «+ своё», счётчик x/7.
   Кнопка «📋 Для Ye!Studio» на странице копирует JSON; автор вставляет его в Ye!Studio кнопкой
   «Вставить из AI» (там галочки и поиск картинок в Яндексе). Если автор просит «дай для Ye!Studio» прямо
   в чате — выдай один блок ```json по памятке.
5. **Картинки автора с диска** — не пиши имена файлов в текст вопросов. Вставляй прямо в пак автора
   (спроси путь к .siq) скриптом `вставить тему в пак.py`: тема встаёт на место первой пустой заготовки
   раунда, рядом остаётся «— копия до вставки», чужие вопросы не трогаются. Предупреди: если пак открыт
   в Ye!Studio или SIQuester — закрыть без сохранения и открыть заново.

## Формат .siq (кратко)

ZIP: `content.xml` первым (deflate, UTF-8 с BOM, компактный XML, schema siq_5, version="5"), медиа в
`Images/`, `Audio/`, `Video/` без сжатия; имена в архиве — percent-encoding UTF-8 (пробел → %20,
`()[],!'&#@~` как есть), в XML — без кодирования. Картинка в вопросе:
`<param name="question" type="content"><item type="image" isRef="True">имя</item></param>`.
Несколько правильных ответов — несколько `<answer>` в `<right>`.

## Проверка готового пака

Пройди все вопросы: факты в ответах, соответствие картинки ответу, единые названия раундов и тем,
пробелы в начале/конце, ступеньки цен, варианты ответов в финале (письменный ответ — добавить синонимы).
Отчёт — файлом в рабочую папку.
