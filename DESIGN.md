# DESIGN.md — Ye!Studio

> Утверждено автором 2026-09-26 (design/redesign-plan.html). На любом конфликте этот файл важнее скиллов
> `redesign-existing-projects` и `web-design-guidelines`.

## Что это за интерфейс
Плотный десктопный инструмент для автора паков, а не лендинг. Ориентиры по плотности — Linear, Raycast
(`VoltAgent/awesome-design-md`). Регуляторы taste-skill: `DESIGN_VARIANCE 3`, `MOTION_INTENSITY 3`,
`VISUAL_DENSITY 7`. Раскладку (шапка, табло, редактор) не переставлять без спроса.

## Незыблемо
- Цвета — только CSS-переменные, значение во ВСЕХ темах `themes.ts` (AGENTS.md, «Оформление»).
- Шрифты — Golos Text (`--font-ui`) и Onest (`--font-display`: цены, темы), `@fontsource-variable`, внутри сборки.
  Выбраны автором из 5 кандидатов (Inter + Rubik ему не нравились).
- Эмодзи в названиях тем и вопросов — содержимое пака, не трогать.
- Логотип «Ye!» с градиентом — айдентика, остаётся.
- Русская типографика: ёлочки «», тире — нормально (запрет тире из taste-skill здесь НЕ действует).
- Иконки — только SVG из `Icon.tsx` (запрет самописных SVG из taste-skill здесь НЕ действует).

## Правила (утверждены)
- Статус клетки — полоской снизу только у черновика и пустых; у готовых полоски нет.
- Цены без `text-shadow`-ореола, `tabular-nums`.
- В теме «Ye!» один акцент — фиолетовый (`--gold #b9a6ff`, `--accent #8b5cf6`); бирюзы и синего нет.
- Градиент только у логотипа «Ye!»; кнопки, бейджи, «БЕТА», фон окна — сплошные.
- Названия тем на табло — текстом, без своей карточки.
- Справка (строка статистики) не выглядит кнопкой: без рамок-пилюль; активная вкладка — линией, без свечения.
- Никаких цветных эмодзи в кнопках и заголовках окон — SVG из `Icon.tsx` (одноцветные ✓ ✎ ▶ ♪ ★ — можно).

## Отклонено автором (не предлагать снова)
- Выбранная клетка без свечения/увеличения — автору нравится как есть.
- Заголовки редактора обычным регистром — КАПС остаётся.

## Как проверять
Любая правка оформления → снимки `app/scripts/design-shots.ts` (все темы) → сравнение до/после →
`web-design-guidelines` по изменённым файлам. Сдавать автору парой картинок, не текстом.
